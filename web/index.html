Sign in to Kaggle

Wan Studio makes videos on your own free Kaggle GPUs (about 30 hours a week). You need:

  1. A free Kaggle account with a verified phone number (kaggle.com/settings → Phone verification). Kaggle only gives GPUs to phone-verified accounts.
  2. An API token: on kaggle.com/settings, in the API section, press Create New Token and copy it.

The token is kept only on this computer and is used only to start and stop your own Kaggle server.
